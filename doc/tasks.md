# Sample task set: earnings-call analytics pipeline

Sample data for this tool, not this project's own backlog. It is modeled on a real backlog: one data pipeline that collects company earnings calls, transcribes them, extracts forward-looking statements, links them to a knowledge graph and checks them against reported results. Names, numbers and details are invented or generalized, and the rows are shuffled, so the list carries no priority order. Working out that order is the tool's job.

## Fields

| Field | Meaning |
|---|---|
| Status | Ready · In progress · Needs verification (built, waiting on a read-back) · Blocked |
| Impact, Effort | S · M · L |
| Depends on | Tasks that must finish, or pass their gate, before this one can finish |
| Gate | A checkpoint where the owner confirms before work goes on |
| Area | Ingest · Extraction · Knowledge graph · Scoring · Orchestration · Publishing · Model platform · Milestone |
